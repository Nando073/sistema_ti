## Instalación

Clonar el repositorio:

```bash
git clone https://github.com/Nando073/sistema_ti.git
```

Ingresar al proyecto:

```bash
cd sistema_ti
```

Instalar dependencias:

```bash
composer install
```

Copiar el archivo de entorno:

```bash
cp .env.example .env
```

Generar la clave de la aplicación:

```bash
php artisan key:generate
```

Ejecutar las migraciones:

```bash
php artisan migrate
```

Iniciar el servidor:

```bash
php artisan serve
```
